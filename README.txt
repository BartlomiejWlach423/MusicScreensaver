MusicScreensaver is Windows screensaver that displays the music currently playing

Controls:
Arrows:
	Left - Previos track
	Right - Next track
	Up - Increase vol
	Down - Decrease vol
Space - Pause/Play playback
Any other key - Close screensaver

Requirements:
Windows 10 or 11
Media player that provides information about playback through Windows media session

Installation:
Right-click Screensaver.scr
Select "Install" option from menu
Configure the screensaver through Windows Screen Saver Settings window
